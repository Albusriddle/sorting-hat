## 4. 架构现状

```
ESP32-WROOM-32D（Arduino）
  ├─ LD3320A（I2C 16/17）：关键词 → 编号 → 预置台词文本
  ├─ XFS5152/CSK4002（I2C 19/18）：念桥接句 + 院名
  └─ Wi-Fi → ws://<笔记本>:8443/v1/voice
        ├─ ready{sid, audio, budget_ms}
        ├─ 上行：listen / vad / text / 0x04 PCM(全零) / bye{dev_ts}
        └─ 下行：tts{start,text} / 0x02 PCM / result{house,reasons,line,scores,announce}
笔记本上位机（Python/FastAPI）
  ├─ 编排：text 优先 → LLM → judge(argmax+反集中+引原话) → 桥接句 → result
  ├─ provider：mock（默认）/ AWS（Transcribe+Bedrock+Polly）
  └─ 观测：sessions.jsonl、/stats、大屏、/v1/sessions、/v1/metrics
```

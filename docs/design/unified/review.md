## 5 对"TuyaOpen + NIM"流程图的评估

**判定：骨架同构、中段黑盒；只可作备链。**

| 段 | 与既有架构 | 判定 |
|---|---|---|
| S3+INMP441+MAX98357、戴上触发 | 同构（H1/H2/H3） | ✅ 可采用 |
| 固件换 TuyaOpen | 异构（现为 xiaozhi/自研） | ⚠️ 换栈 4 h，撞 G3 |
| ASR 走涂鸦/中转 | 异构（现为 Transcribe） | ⚠️ 只作第三 provider |
| LLM 换 NIM | 异构（Claude 主、Nemotron 第二判官） | ❌ 主判官不可换 |
| TTS+"复刻音色" | 异构（CosyVoice instruction） | ❌ 权利风险 |
| 喇叭在头顶 | 异构（后壁+密封后腔） | ❌ 破 ≥25 cm 与"顶部不放重物" |

**缺四层**：判决（让模型出台词＝把 `house` 交回 LLM，违 §8.1 的代码 `argmax`）、反集中（连 3 次同院 ×0.85，无）、降级（云断即零兜底）、观测（云不给 t1–t4，TTFC 讲不出来；A §7.6 点到）；另缺协议层与物理层。

**延迟与成本**：多两跳跨境。实测冷 TLS 0.78–1.76 s，多两个冷连接即 +1.5–3.5 s，常连接下估 2.6–4.5 s（需实测），打穿 1.8 s 上台线；TTFV 0.6 s 靠沉吟可保，真内容首字救不回。成本由 ¥0.145/次 变成"未公开价+GPU 时租"，不可预算。NIM 目录已核到 `nemotron-super-49b-v1`/`ultra-253b-v1`，"跑 Super"成立；"Super 120B"与目录不符，**需核实**。

**音色权利**：分院帽中文配音是配音演员的表演，《民法典》1023 条对声音参照肖像权，无书面同意即侵权；角色名+音色叠加＝华纳 IP 与声音权双雷，"标注致敬"不是抗辩；《AI 生成合成内容标识办法》2025-09-01 起要求显式标识；涂鸦云是否允许自带复刻音色看条款（需核实）。裁决：**不做复刻**，用 instruction 描述的原创老年男声，并把"评估过风险才选原创"写进 pitch。

**AWS 加分：不能。** 要 Transcribe+Bedrock+Polly 兜底+CloudWatch 留证；新图全无，架构图找不到 AWS 组件。除非主链路仍走 AWS。

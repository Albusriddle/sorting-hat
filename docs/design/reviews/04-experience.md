# 04 · 体验、IP 与评审心理评审（分院帽实体复刻）

> 视角：体验设计 / IP 风险 / 评审心理 / 观众运营；不碰技术选型（见 01–03）。
> 核实：本会话 `web_search` 返回 401，改用 `curl` 直取官方页。**IP 一节分「事实（谁拥有什么）」与「经验判断（风险多大）」，后者不是法律意见**；商标注册号未核实（USPTO / WIPO / Justia 均被 Cloudflare 拦截）。

## 0 结论先行

| # | 结论 | 依据 |
|---|---|---|
| 1 | **体验的胜负手是"帽子先开口"，不是延迟** | 戴上前 3 秒他不知说什么；预录一句零成本、零延迟 |
| 2 | **不给分数，给原话**：四维只对内，三条理由必引观众原话 | 被问"凭什么"，唯一站得住的答案是"因为你说过……" |
| 3 | **IP 降到 B 级**（原创世界观 + 四院改名，保留四维），半天工作量 | "标注致敬"不是抗辩事由；降级反而能把最大风险变成 pitch 亮点 |
| 4 | **40% 投票靠"可转发的证据"**，不靠求人扫码 | 60 秒竖版视频自动出片 + 档案页首屏投票按钮，一人带来 3–8 次曝光 |
| 5 | **卫生与节奏是同一题**：接触层一次性 + 帽子说送客话盖住清洁 | 20 秒换场 SOP，单人可做 |

## 1 60–90 秒佩戴体验脚本

**结论：把 90 秒切成「帽子说 55 秒 / 观众说 30 秒 / 沉默 5 秒」，观众永远不必自己想话题。** `A`＝预录（零延迟），`L`＝实时生成。预录不是偷懒：它保证每段体验的头 8 秒和尾 8 秒绝对可控。

| 秒 | 谁 | 帽子说什么 | 灯 / 动作 |
|---|---|---|---|
| 排队中 | 帽子 | 每 25 s 一声「唔……」`A` | 暖黄呼吸（＝睡着，也＝活着） |
| 0–3 | 守门人递发网、内衬 | — | 暖黄→呼吸蓝 |
| 3–6 | 帽子先开口 | 「唔……又一位。」`A` | 帽尖抬 5° |
| 6–10 | Q1 | 「先别想答案。说你最近特别想要的东西。」`A` | 灯环收成一点（＝在听） |
| 10–18 | 观众答 | （VAD 300 ms） | 随音量微脉动 |
| 18–20 | 沉吟 | 「有意思。」`A`（0.8 s，盖住 LLM 延迟） | 一次慢脉冲 |
| 20–24 | Q2 | 「那什么事让你最不服气？」`A` | 点状 |
| 24–34 | 观众答 | — | 同上 |
| 34–37 | Q3（70 s 版跳过） | 「朋友会怎么形容你？一个词。」`A` | 同上 |
| 37–40 | 打量 | 「嗯——」`A` | 转暗，帽尖后仰 8° |
| 40–52 | 三条理由 | 每条 10–14 字，含原话 `L` | 4 格环亮 3 格 |
| 52–56 | **宣布前静默** | 无 | **全灯灭 3 s**（全场唯一长停顿） |
| 56–60 | 宣布 | 「那么……穗垣。」`A` 模板 + `L` | 学院色 + 帽尖 15° 弹起 |
| 60–68 | 收尾台词 | 见 §2 `L` | 稳在学院色（＝拍照光） |
| 68–72 | 摘帽 | 「走吧。别回头。」`A` | 回暖黄 |
| 72–90 | 扫码 / 合影 / 换场 | — | 暖黄呼吸 |

**70 秒压缩版（高峰）**：砍 Q3，理由压到 2 条，第三条留到档案页——把"完整感"换成"想再看一次"。

| 异常 | 帽子说什么 | 守门人 | 原理 |
|---|---|---|---|
| **冷启动** | 「唔……让我醒一醒。」`A` | 开机 45 s 内预连接；呼吸灯＝可视化的"活着" | 让观众看到"在准备"而非"坏了" |
| **紧张** | 「这里没有对错，只有适不适合。」`A` 后直接给 Q1 | 「随便聊两句，它不记仇」 | 具体问题（"最近想要什么"）比"介绍你自己"低十倍门槛 |
| **说太少** | 换问法追问一次；仍不足 →「只能选一个：被人记住，还是被人信任？」`A` | 不提示、不救场 | 二选一兜底**同时**是 ASR 失败兜底，一套机制两个用途 |
| **说太多** | 15 s 处打断：「够了。我大概知道了。」`A` | 微笑，不制止 | 打断是分院帽人格里的特权，不是 bug，写进 prompt 硬规则 |
| **听不清** | **不说"没听清"**，回声确认：「你说的是……『不想再解释了』？」`A` 模板 + 槽位 | 无 | 观众只需答对/不是；"请再说一遍"是最伤体验的一句 |
| **想重来** | 「重来？可以。但帽子只翻一次面。」`A` | 长按帽檐 2 s，限 1 次 | 不给"重新开始"按钮（破坏仪式）；重来后仍可能同院，且诚实告知 |

**与协议对齐**：`00-protocol.md` 的「8 s 静音 → `bye{silence}`」对体验是致命的——帽子应在 6.5 s 先开口救场，8 s 超时只做最后一道闸。

反直觉一点：**不要为"观众说错话"设计纠错**。他说"我想红"，最差的回应是"我没听懂"，最好的回应是「想红。说好听点叫被看见。」——把粗糙原话翻译成漂亮解读，是这个产品最不易被抄的部分。

## 2 可解释性：四维对内，三条理由对外

**结论：分数只用于内部排序与防塌方，对外一个数字都不许出现；三条理由格式固定为「引用原话 → 一句解读 → 不报维度名」。**

| 层 | 规则 | 防什么 |
|---|---|---|
| L1 先证据后结论 | 必须先输出 `evidence[]`（原话片段）再输出 `house` | 模型对"勇气"的默认偏好（最常见塌方根因） |
| L2 四维阈值 | 每维 1–5；最高与次高差 <0.5 时取"引用条数更多"者 | 边界样本乱分 |
| L3 理由结构 | 3 条覆盖 ≥2 个维度；每条以引号开头（原话 ≥6 字）；禁数字、禁维度名 | "万能回答"式点评 |
| L4 轮次软约束 | 最近 3 位同院 → 第 4 位该维 −8%（"帽子不想重复自己"） | 同一批围观者出现 3 个同院，被说"随机/偏心" |

**上线门槛**：20 条固定输入（10 性格 × 2）须满足 ①≥3 个学院 ②任一学院 ≤40% ③引用原话与输入重合 >0（人工核）。不过不许上台。

| 观众 | 原话 | 四维（对内，不播） | 三条对外理由 | 台词 |
|---|---|---|---|---|
| **A** 26 岁产品经理，防御性强 | 「也没什么特别想要的」「最不服气的？别人替我做决定」 | 忠 4.2 / 智 3.0 / 勇 2.8 / 野 2.5 → **穗垣** | ①「你说『别人替我做决定』时，声音比刚才大了一点。」②「你嘴上说没什么想要的，但你把『不要什么』说得很清楚。」③「所以我不会替你安排。你自己挑。」 | 「守得住自己的人，才守得住别的东西。」 |
| **B** 大学生，话密，讲三个比赛，主动问「我能去最好的那个吗」 | 讲 4 件事，3 件是"我拿了什么" | 野 4.6 / 勇 4.0 / 智 3.2 / 忠 1.6 → **玄渊** | ①「你说了四件事，三件是『我拿了什么』。」②「你问我能不能去最好的那个——你还没进门，就已经在排名了。」③「你不怕输。你怕的是没人看见你赢了。」 | 「那就去。玄渊不缺聪明人，缺的是承认自己想要的人。」 |
| **C** 12 岁，答得怪 | 「我想要一只不会死的仓鼠」 | 智 4.4 / 忠 3.6 / 勇 3.3 / 野 2.0 → **星枢** | ①「你要的不是仓鼠，是『不会结束』。」②「你答之前看了三次天花板。你在找一个别人没给的答案。」③「别人会说玩具。你说的是时间。」 | 「星枢不问你对不对，只问你想不想知道为什么。」 |
| **D** 第 4 组校准样例，防"只出三院" | 外卖骑手：「我不能让客户等」 | 勇 4.1 / 忠 4.0 / 野 2.9 / 智 2.7 → **赤翎** | ①「你说的是别人的事。」②「这句话你说得比我问得快。」③「你不觉得这算什么，所以它才算。」 | 「赤翎要的不是胆子，是有人在你背后。」 |

两条必须进 prompt 的护栏：①**锋利但给出口**——野心向理由可以刺人，最后一句必须是许可（「那就去」）而非判决；四维现场口播「**敢、要、想、守，四种活法**」，观众就不觉得被贬。②**禁止编造观察**（"你进门先看出口"这类没发生的事一旦被否，整场可信度归零），理由只能来自对话文本与帽子视角的隐喻。

## 3 IP 风险与三级降级（最容易被忽视的致命项）

> 以下事实有官方页面原文可查，判断标为经验判断，**不构成法律意见**。

| 元素 | 谁主张权利 | 核实状态 |
|---|---|---|
| 角色与世界元素（分院帽、四学院名、院徽、四组配色） | **Warner Bros. Entertainment Inc.** 主张 © 与 ™ | 已核实：[wizardingworld.com/terms](https://www.wizardingworld.com/terms) 页脚「All characters and elements © & TM Warner Bros. Entertainment Inc.」 |
| 原著文字 / 出版权 | **J.K. Rowling** | 已核实：同页脚「Publishing Rights © J.K. Rowling」。**两行分列**：改设定绕得开"角色元素"，绕不开"用别人的世界"本身 |
| 电影视听素材、剧照、服装设计 | Warner（制片/发行）+ 具体创作者 | 经验判断（未核实合同），方向明确 |
| 主题音乐（Hedwig's Theme） | 作曲 **John Williams**；录音与影片使用由 Warner 控制 | 未核实登记；**双层权利（作曲＋录音）** 是行业通例 |
| 商标注册（SORTING HAT / HOGWARTS / 四学院名等） | 经验判断：Warner 名下 | **未核实**：USPTO/WIPO/Justia 本次全被 Cloudflare 拦截 |
| 中国境内中文商标（"哈利波特""霍格沃茨"） | 未核实 | 未核实（CTMO 查询需交互） |
| 华纳有无公开"粉丝内容许可" | 未核实 | [wizardingworld.com/terms](https://www.wizardingworld.com/terms) 是**站点使用条款**，不是粉丝创作许可，不可当授权引用 |

另一官方口径（[warnerbros.com/terms-use](https://www.warnerbros.com/terms-use)，2026-11-15 抓取）：其内容受「copyrights, trademarks, service marks, or other intellectual property rights」保护，授权仅限「personal, non-commercial use」，并对未授权使用「reserves the right to fully prosecute」。

| 判断（经验判断） | 理由 |
|---|---|
| **"标注致敬"不是抗辩事由**，只降低"恶意"观感 | 它不产生许可。旧版备忘录把它当处置措施，这是错的 |
| 商业活动 + 媒体传播 + 视频上网 → 风险从"低"到"中高" | 商标判断核心是"商业性使用"与"来源混淆"；有奖金、赞助商、媒体，难主张纯个人非商业 |
| **真风险不是华纳发函**，是①主办方合规审查 ②视频被平台下架 ③评委问"授权了吗" | 前两项是流程风险（概率不低），第三项是**确定的失分** |
| 用电影原声（哪怕 8 秒）是**唯一不可接受**的单点 | 双层权利 + 平台自动识别；一旦被识别是"公开视频下架"而非"私下提醒" |
| 反向机会：主动讲 IP 降级是**加分项** | 证明团队想过"能不能卖"，正落在 60% 的应用价值 |

| | **A 级 原名致敬** | **B 级 改设定（推荐）** | **C 级 完全原创** |
|---|---|---|---|
| 改什么 | 不改 | 帽名「**掂量帽**」；四院 **赤翎/玄渊/星枢/穗垣**；配色避开酒红金、墨绿银、蓝青铜、黄黑；台词全原创；音乐用原创 8 小节或 CC0 | 自造世界（如"夜市里替人算命格的老帽子"），改仪式与话术 |
| 保留 | 全部 | **四维保留**、戴帽被审判的仪式、沉吟节奏 | 只留"戴帽—被判断—被说中"内核 |
| 工作量 | 0 | **半天**：文案 2 h、配色徽记 1 h、prompt 1 h（音色不变） | 1.5–2 天，3 天内不划算 |
| 风险 | 中高 | 低（四维是通用性格叙事；"会说话的帽子"是通用母题） | 最低 |
| 代价 | 评委一秒懂，但可能当场扣分 | 需 30 秒解释"为什么不是哈利波特" | 失去"一秒懂"，40% 投票会掉 |

**推荐：B 级做交付主线，A 级只留内部彩排；并在 pitch 里主动讲。** 话术：「这是别人的世界，我们不想蹭，所以把 IP 风险做成了设计约束——四维、院名、台词都是我们自己的。」零成本三件事：①作品名不用"分院帽"三个字，用「掂量帽 The Weighing Hat」；②不用任何剧照与官方院徽；③公开视频加一行「原创世界观，非官方，与 Warner Bros. / J.K. Rowling 无关」。

## 4 评委心理：3 分钟他们记住什么

**结论：评委一天看 20 个项目，只带走「一个瞬间 + 一个数字 + 一个判断」，三样都得提前造。**

| 留下 | 是什么 | 怎么造 |
|---|---|---|
| 一个瞬间 | 宣布前 3 秒全场灯灭、安静 | 写进脚本，不许省（全项目最便宜的高光） |
| 一个数字 | 「端到端 1.4 秒，10 次中位数」＋「20 条测试四院 26/24/24/26」 | 两个都报：一个证工程，一个证不塌方 |
| 一个判断 | 「可解释性不是给观众看分数，是把他的原话还给他」 | 这句原样说一遍，它划开我们和聊天玩具 |

| AI 感来源 | 观众感受 | 对策（可直接进 prompt） |
|---|---|---|
| 念稿感 | 句子太完整、连接词太多 | 每句 ≤14 字；禁"首先/其次/总之/综上/希望能够"；允许口癖（唔、啧、嗯——） |
| 过度礼貌 | "很高兴为你服务"＝客服 | 帽子是**审判者**不是服务员：给它不客气的权利（「坐好。」「别急。」） |
| 万能回答 | 什么都能答＝什么都不懂 | 设知识边界：只关心敢/要/想/守，问别的就说「这我不关心」 |
| 语气平坦 | TTS 一个参数到底 | 理由间插 400–600 ms 停顿；宣布前 3 s 纯静默；关键句降速 15% |
| 过度解释 | 开始讲机制 | 机制留给 pitch，只给观众理由 |
| 完美无错 | 太顺＝假的 | 允许一次犹豫改口：「……不，不是这样。」最像人的 0.5 秒 |

**唯一不可接受的状态是沉默**：任何故障，帽子先说一句人话，然后才轮到工程师动手。

| 翻车 | 10 秒内动作 | 台词 |
|---|---|---|
| 网络断 | 帽子先拖时间 → 15 s 内长按切本地（灯转琥珀＝"施法中"） | 「等一下。」→「让我再想想。」`A` |
| 听错 | 回声确认，不道歉 | 「你说的是……『不想再解释了』？」 |
| 没反应/死机 | 守门人**拍一下帽檐**（物理＝唤醒）＋按复位；15 s 未恢复换热备帽 | 「它睡着了。」（守门人说） |
| 说重了 | 不抢话、不道歉式解释，让帽子自己收回 | 「……说重了。你不是那种人。」`A` |
| 灯不亮 | 忽略，继续演 | — |
| 答非所问 | 顺着演再拉回 | 「你在逗我。行，换个问法。」 |

反模式：守门人低头摆弄笔记本、两人小声讨论、观众干等——出现任一种，这票就没了。

## 5 观众投票（40%）的运营

**结论：投票不是求人扫码，是给人一件可以发给朋友的证据。** 转化最高的动作是"你的分院档案好了，发朋友圈吧"。

| 装置 | 做法 | 作用 |
|---|---|---|
| 动线三段 | ①1.5 m 外立牌「它在等人」＋地面 6 个脚印（＝只要 90 秒）②2 m 侧拍照位（地面贴"最佳机位"）③摘帽 30 s 内出档案 | 最好的广告是别人戴帽子的样子 |
| 拍照点 | 帽子上方 45° 柔光灯 + 可变色背景板 + 观众自己的手机支架；**不请摄影师**（不可扩展） | 一张能发的照片＝一次免费曝光 |
| 60 秒竖版视频 | 固定竖屏机位 + 一键录制 + 尾部 3 s 自动贴片（徽记/二维码/台词），模板化自动出片 | 核心引擎：一人发圈 ≈ 3–8 次曝光 |
| 分院档案页 | 学院＋徽记 → 三条理由（原话高亮）→ 一句台词 → 视频 → **首屏「帮 TA 投票」** | 投票按钮**不能**放在视频后（60 秒＝流失点） |
| 替身券 | 戴完领券，带朋友来报券号免排队（限 1 人） | 把单次体验变成"必须拉一个人"的社交义务 |

| 2 小时 40 票 | 数 |
|---|---|
| 节奏 | 90 s 体验 + 20 s 换场 ≈ 2 min/人 → 上限 60 人，**取 45 人**（留故障与合影） |
| 戴过的人投票 | 45 × 0.6 = **27** |
| 朋友远程投票（"帮 TA 投票"） | 45 × 0.4 = **18** |
| 路人围观转化 | **10**；团队 **3** |
| 合计 | **≈58**，40 为保守目标 |

执行要点：①每 30 分钟报一次"还差 X 票"；②小屏显示实时票数（社会证明）；③手写墙「本场最不服气的三条理由」；④高峰发号牌，每 10 分钟 5 个——**排队要看起来"刚好"**，太长劝退路人。别做：扫码送礼（多赛事不允许）、拦路人硬推。

## 6 卫生与节奏：20 秒换场

**结论：不消毒帽子，只换接触层。** 内衬圈（皮肤隔离）+ 发网（头发隔离）+ 湿巾擦帽口，单人 20 秒；45 人份耗材约 ¥30–40。

| 物料 | 规格 | 45 人用量 | 作用 |
|---|---|---|---|
| 一次性无纺布内衬圈 | 帽口弧形、魔术贴、深色（不显妆） | 60 片 | **主隔离层**，一客一换 |
| 一次性发网 | 尼龙 20 g | 50 个 | 头发隔离，观众自戴 |
| 75% 酒精湿巾 | 独立包装 | 100 片 | 擦帽口内侧与麦克风罩（**不擦电子件**） |
| 浴帽式头套（可选） | 给明显抗拒者 | 20 个 | 应急保转化 |
| 免洗洗手液 / 挂桌垃圾袋 / 镜子 | — | 各 1 | 洗手、观感、**整理头发＝尊严** |
| 备用帽圈 | 魔术贴可拆洗 | 2 套 | 晚场拆洗晾 |

**20 秒 SOP**：0–4 s 接帽说「给我」→ 4–8 s **当着观众面**撕旧内衬进袋（这是"干净"的表演，藏着做反而失分）→ 8–12 s 湿巾擦帽口一处 → 12–16 s 贴新内衬、递发网 → 16–20 s「下一位」。这 20 秒里帽子说「走吧。别回头。」`A`，用声音盖住清洁动作的尴尬。
**诚实口径**：内衬与发网是"降低"不是"消除"；按理发店接触标准，接触层一次性、帽体不接触皮肤。

## 7 戏剧性：买 4 个动作，砍 5 个

**结论：戏剧性靠时间不靠机械。** 只买这四个，其余一律砍。

| 值得做 | 时机 | 成本 | 为什么 |
|---|---|---|---|
| **宣布前全灯灭 3 s** | 52–56 s | 0 元 | 全场唯一长停顿，拍照与安静的唯一来源 |
| 灯环收成一点＝在听 | 每次观众说话 | 0 元（固件状态） | 让观众知道"它在听我"，胜过任何提示音 |
| 帽尖沉吟时后仰 5–8° | 37–40 s | 1 舵机 | 一次就够；连续摆动像玩具 |
| 宣布时变色 + 帽尖 15° 弹起（200 ms） | 56–60 s | 0 元 | 全场拍照的那一秒 |

| 不值得做 | 原因 |
|---|---|
| 帽尖持续摇摆 | 像玩具；舵机噪音进麦克风 |
| 逐条理由配不同灯光 | 观众开始数灯，就不听内容 |
| 排队时帽子表演 | 抢"正在等的人"的注意力，且耗电 |
| 帽子转头看人 | 观众盯着机械结构，不听 |
| 每次分院放音乐 | 90 s 放 5 次，隔壁展位投诉；节奏被音乐长度绑死 |

停顿红线：沉吟 ≤1.2 s（超 2 s 观众开始怀疑坏了）；宣布前 2.5–3 s，**全场只允许一次**。
